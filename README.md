
This is a game coded by 2 students from ESTACA as a final project in 1st year. 
It's an implementation of the game Carthographer by Jordy Adan that can be played localy. 
It works using the Raylib library (see https://github.com/raysan5/raylib). the lib can either be installed via vcpkg if you're using Visual Studio or directly downloaded as a part of the project in the codeBlocks branch
It was made to be compiled using MSVC compiler but can alternatively be compiled with gcc and clang using an adequate configuration (see CodeBlocks branch).
We hope you'll enjoy it.

Github link : https://github.com/TimTheGuyDrifitingOnTheRunway/Carthographers.git
